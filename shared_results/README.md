# shared_results

Actual output files for the handoff. The pipeline writes everything under
`results/`, which is gitignored (regenerated by re-running the pipeline). This
folder is a tracked copy of the results that matter for continuing the work, so
they travel with the repo. See `PROGRESS_REPORT.md` section 0 for full context.

## pcoc_ER_gain/

Raw PCOC `pcoc_det.py` output, one file per gene, for the PRIMARY analysis:
ER ancestral reconstruction, convergent class = gains of diurnality (10 events).

Columns: `Sites` (1-based trimmed-alignment column), `Indel_prop`,
`Indel_prop(ConvLeaves)`, then the posterior for each model: **`PCOC_V1`** (the
one that matters: probability of a convergent profile change), `PC_V1`, `OC_V1`.

Blank posterior cells are sites whose convergent-model posterior underflowed to 0,
i.e. strongly rejected, not untested. Every site was evaluated. `PC_V1` is a
constant 0.5 here (a fixed property of this PCOC build), so ignore that column.

Headline result: zero convergent sites. The single highest `PCOC_V1` anywhere is
0.30 at RORB site 1 (first alignment column, a likely edge artifact). This null is
pending `pcoc_sim` power calibration before it can be read as biological, because
the scenario marks half the tree convergent (see report section 0.3).

The three sensitivity sets (ER_reversal, ARD_gain, ARD_reversal) were scaffolded
but not run; they are not here yet.

## scenario/

- `transition_branches_ER.csv` primary transition set, 15 branches WITH direction
  (10 gains, 5 reversals). This is what feeds PCOC and step 08.
- `transition_branches_ARD.csv` the ARD sensitivity reconstruction, for comparison.
- `convergent_events_ER.csv` per-event branch membership (transition node + the
  descendant branches that stay derived); the exact input to the PCOC scenario.
- `node_states_ER.csv` reconstructed nocturnal/diurnal state for every tree node.
- `transition_branches_flagged.csv` step 08 hemiplasy output: 0 of 15 flagged.
